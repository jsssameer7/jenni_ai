SECURITY

Privacy by design,
security by default

Every feature was designed to keep your data local, your PC safe, and your secrets protected.

🔐

Zero Secrets Policy

Regex filters actively prevent saving passwords, tokens, or API keys in memory.

🛡

Allowlist Execution

Only pre-approved applications and websites can be launched. No arbitrary shell commands.

📁

Path Traversal Guard

File access is confined to explicitly approved directories. System folders are inaccessible.

✅

Confirmation Gateway

All sensitive PC actions require your explicit approval before execution.

🔒

Token Auth for Remote

Remote access from your phone requires a secret token. Local access is automatically trusted.

😗

No Internet Required

Jenni AI runs fully offline. Ollama, MongoDB, and all core features work without internet.
